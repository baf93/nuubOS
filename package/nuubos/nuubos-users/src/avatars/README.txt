nuubOS built-in profile pictures
================================

The 24 built-in avatars are rendered with DiceBear (https://www.dicebear.com/,
avatar styles 10.x) from fixed seeds on a square retro-palette background, and
rasterized to 256x256 PNG. The artwork is otherwise unmodified; the UI rounds
the corners. Regenerate with tools/avatars/generate.sh in the nuubOS repository.

01-08  "Pixel Art" style (seeds Felix, Aneka, Mimi, Sasha, Nova, Pixel, Kiwi, Luna)
       Design: DiceBear (https://www.dicebear.com)
