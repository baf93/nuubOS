nuubOS System Sound Set v3

Original synthetic PCM assets created for nuubOS. No third-party samples are
used. They are distributed under the same MIT license as the nuubos-audio
package. The cues deliberately use a low, soft tonal palette to avoid
harshness on small handheld speakers:

- navigation.wav: subtle navigation pulse
- select.wav: soft upward gesture
- back.wav: soft downward gesture
- quick-settings.wav: Quick Menu / Settings open cue
- boot.wav, restart.wav, poweroff.wav: power cues (Power Sounds)

48 kHz / mono / signed 16-bit PCM WAV.
