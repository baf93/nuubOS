nuubOS test sound

nuubos-test-jingle.wav is an original synthesized 4-bar tune on the nuubOS
motif (lead D4-D5, bass and chords, ~11 s, ending on the boot cadence), generated
by tools/sounds/make-system-sounds.py together with the system sounds. It
contains no third-party samples or copied musical recording. It is
distributed under the same MIT license as the nuubos-audio package.
