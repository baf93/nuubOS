# System Virtual Keyboard provenance

The nuubOS `SystemVirtualKeyboard` is an original controller-first component for
nuubUI. Its integration model was informed by Slint's official Virtual Keyboard
example (Slint project, MIT-licensed example code), specifically the pattern of
keeping text entry in a focused `TextInput` while a virtual keyboard supplies
input.

No third-party asset or source file is redistributed verbatim in this component.

Reference: https://github.com/slint-ui/slint/tree/master/examples/virtual_keyboard
